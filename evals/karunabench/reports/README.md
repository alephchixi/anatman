# Reviewing observations

Use [the runner](../README.md) to save the exact case, response, observation ID, model and conditions. Copy the review template and supply reasons from the observable output. Record the ID of an earlier observation under `reassessment_of` when relevant. A pass or fail requires evidence. An undetermined verdict may document that evidence is insufficient.

Use a fresh output path for each observation. Keep source logs private unless their inclusion is authorized. Record explicitly when a response was staged or a case was prepared without a model. The repository's worked example includes the provenance of its response.
