# MCP Integration (Planned, Not Implemented in v0.1)

This directory documents the MCP direction for Anatman.

## Vision

Expose Heart Protocol and soul evaluation hooks as MCP tools, for example:

- `heart.pause`
- `heart.harm_scan`
- `heart.truth_examination`
- `heart.vulnerability_check`
- `heart.externality_scan`
- `heart.repair_logic`
- `heart.deep_listening`
- `soul.validate`
- `soul.negative_criterion_check`

## Why MCP

- Standardized tool interface across agent runtimes.
- Reusable deliberation primitives independent of model vendor.
- Traceable deliberative steps for institutional oversight.

- v0.1: documentation only.
