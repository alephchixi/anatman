# Exocapitalist Audit Reports

This directory holds audit reports generated by the
[`exocapitalist-audit`](../../skills/exocapitalist-audit/SKILL.md) skill.

Each report applies the Five Movements of exocapitalism
(Scale, Fold, Lift, Drag, Last-Mile — Poliks & Trillo) to a soul or a
proposed integration, and separately records whether Sadin's negative
criterion holds.

## Naming

`<soul>_<YYYY-MM-DD>.md` — e.g. `bodhisattva_core_2026-04-17.md`.

For integration audits (not tied to a single soul) use
`<integration-name>_<YYYY-MM-DD>.md`.

## Generating a Report

See `skills/exocapitalist-audit/SKILL.md` for the full procedure. The
optional `skills/exocapitalist-audit/helper.py` script emits a
pre-populated Markdown template from a soul file; the reviewer fills
in the judgment blocks and attaches the finished report to the PR
that motivated the audit.

## Retention

Reports are part of the repository history; do not delete them. If a
report becomes inaccurate because the audited soul has changed,
supersede it with a new dated report and link back to the original.
