# Anatman Skills

Skills are reusable procedures for high-friction workflows in this repository.
Each skill defines when to trigger, what inputs are required, and where outputs
must be written so results stay auditable.

## Available Skills

- `soul-redteam`: adversarial scenario report generation for one soul.
- `soul-lineage`: cross-soul and pack lineage/tension ecosystem mapping.
- `pack-builder`: guided authoring for new souls and ethics packs.
- `exocapitalist-audit`: Five Movements extraction-risk audit for PR review.
- `soul-to-claude`: compilation of soul + packs + protocols into Claude Code.

Canonical index: `docs/skills.md`.
