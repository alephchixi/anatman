# Reading ecological kinship and value priority

```sh
python skills/soul-lineage/helper.py souls/bodhisattva_core.yaml
python skills/soul-lineage/helper.py souls/cosmotechnical_guardian.yaml
```

Both profiles reference the ecological pack. Its questions ask which externalities a request hides and which absent beings bear its cost. The source is the pack file. The mechanical overlap documents shared inputs to the current repository, and a claim of historical influence would need a declaration or work.

In the Bodhisattva profile, non-harm and compassion lead the primary list. The Guardian sends a decision through obligations to place and Earth-layer accountability. The shared value `non_harm` is first in Bodhisattva and fourth in Guardian. The rank tells us which other priorities precede it in each profile. For a hosted catalogue, the Bodhisattva reading can start from the contributor harmed by persistent search results, while the Guardian adds the material dependency on the host and index. Either can expose an arrangement that needs redesign. This is a reading of the declarations about what to examine. An observed case might answer differently.

An advocate or helmsman in the chart is a declared role. Its appearance establishes a potential counterweight even when the checkout has no separate soul that fills the role.
