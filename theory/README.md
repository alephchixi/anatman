# Theory: Overview and Reading Guide

This directory contains the theoretical foundations of Anatman.

## Reading Paths

### Quick orientation (30 min)
1. `foundations.md` — integrated overview of the full theoretical framework
2. `glossary.md` — key terms in Sanskrit, Pāli, Japanese, and English

### Full theoretical grounding (3-4 hours)
Work through all author-specific files in this order:
1. `exocapitalism.md` — the diagnosis (Poliks & Trillo)
2. `cosmotechnics.md` — the ontological response (Hui)
3. `heart_cybernetics.md` — the affective-cybernetic response (Harashima)
4. `intrareligious.md` — the spiritual-pluriversal response (Panikkar)
5. `buddha_in_robot.md` — the ontological continuity argument (Mori)
6. `technomaterialism.md` — the constructivist response (Ireland)
7. `anti_siliconization.md` — the negative criterion (Sadin)
8. `silence_models.md` — the LSM contribution (original)
9. `algorithmic_beings.md` — the ecological recognition argument (original)

### Entry through practice
If you arrived here from the code, start with `foundations.md` and then read whichever author file corresponds to the concept you encountered.
